# 术语图鉴（自建术语库）

参考 [vibe-hub.org](https://vibe-hub.org) 的**领域与分类结构、页面布局**做的纯静态术语库页面，外加一个「防 AI 味」图鉴板块和一个「知识文章」导航页。

> 说明：领域划分 / 分类结构 / 页面布局方式参考了 vibe-hub.org；全部释义文案为本站原创撰写，示意图为按术语含义自行绘制的简化示意（未搬运原站代码与文案）。

## 使用

```bash
# 在本项目目录下起一个静态服务器
python -m http.server 8613
# 打开 http://127.0.0.1:8613/
```

也可以直接双击 `index.html`（无需构建、零依赖）。

## 结构

- **术语库（默认视图）**：9 大领域 / 24 个分类 / **385 条**
  - 前端 146、后端 73、产品 25、测试 14、技术栈 20、AI 43、Git 15、设计风格 24、防 AI 味 25
  - 吸顶筛选栏：搜索框 + 横排领域页签；左侧窄栏：竖排子分类页签
  - 主区标题「{领域} VibeCoding 术语」（防 AI 味为「防止 AI 味儿」）
- **知识文章（导航栏切换）**：12 篇文章按 4 个主题分组，点卡片跳转 book.oiloil.org 原文

## 功能

- **大白话搜索**：搜「弹出来的框」能找到「模态框」；分词 + 字符覆盖率模糊匹配，`/` 快速聚焦
- **领域 / 子分类切换**：点筛选栏领域页签换领域，侧栏子分类页签过滤区块，滚动时自动高亮
- **收藏**：卡片右上角 ★（localStorage 持久化），筛选栏「收藏」页签只看收藏
- **详情弹窗**：点卡片看分类路径、释义、大图示意，可一键复制「术语（English）」
- **亮 / 暗主题**：跟随系统 + 手动切换；**响应式**：窄屏侧栏变横向胶囊条
- **场景适配**：内容超出演示区的场景自动「测真实尺寸 → 等比缩放居中」

## 文件结构

```
index.html         页面骨架（导航 / 吸顶筛选栏 / 侧栏 / 术语区 / 知识文章区 / 弹窗）
styles.css         页面框架样式（设计令牌、卡片网格、弹窗、主题、知识页）
scenes.css         示意图样式（s-* 基础组件体系 + 领域场景容器 + 防 AI 味场景）
design-scenes.css  设计风格领域场景的兼容样式层（按需提取的内部类规则）
scenes.js          360 个术语的示意图结构数据（类名归一化到 s-* 体系）
scenes-aif.js      防 AI 味 25 条的示意场景（自创反例句与迷你界面）
data.js            DOMAINS 数据（9 领域 385 条，含原创释义）+ ARTICLES 文章清单
app.js             渲染、搜索、收藏、弹窗、主题、视图切换、滚动监听、场景适配
```

## 如何修改

- **改释义**：直接改 `data.js` 里对应条目的 `desc`
- **加术语**：在 `data.js` 对应分类的 `terms` 里加 `{ id, zh, en, desc }`；若 `scenes.js` 没有对应示意图则只显示文字（自动兜底）
- **加文章**：在 `data.js` 的 `ARTICLES` 对应分组里加 `{ slug, title, desc }`
- **调示意图样式**：`scenes.css`（基础类 `s-` 前缀）与 `design-scenes.css`（原始类名以 `s-raw-` 钩子保留，可单独覆盖）
